# 안녕 친구들 👋

30개월 아이가 인사하는 연습을 하는 웹 게임입니다.
동물 친구, 또래(3살) 친구, 선생님 캐릭터가 먼저 "안녕~" 하고 인사하면, 아이가 "안녕~" 하고 대답하는 놀이예요.

## 실행 방법
마이크는 **https** 주소나 `localhost`에서만 동작합니다.

- 휴대폰: https://wjdgns9726-afk.github.io/-/ (이 브랜치에 push하면 자동 배포)
- 컴퓨터에서: `cd hello-game && python3 -m http.server 8000` 후 `http://localhost:8000`

추천 브라우저: 안드로이드 크롬·삼성인터넷, 아이폰 사파리 (음성 인식 지원)

## 기능
- **"안녕" 음성 인식**: 안뇽·안농·아녕·안녕하세요처럼 아이 발음도 넉넉하게 인정
- **목소리만 내도 성공 모드**: 발음이 어렵거나 부끄러워할 때, 소리만 내도 칭찬 (기본값)
- **캐릭터**: 토끼, 곰돌이, 멍멍이, 야옹이, 펭귄, 사자 / 민준, 서아, 지호 / 선생님
- **사진 친구**: 실제 어린이집 친구·선생님 사진을 넣어 그 친구에게 인사 연습 (사진은 기기에만 저장, 길게 누르면 수정·삭제)
- **선생님에게는 "안녕하세요~"** 를 알려줘요
- 아이 이름을 넣으면 캐릭터가 "도빈아 안녕~" 하고 불러줘요
- 부끄러워서 말을 못 하면 👋 버튼(손 흔들기)으로 먼저 시작해도 돼요. 실패는 없고, 캐릭터가 "괜찮아~" 하며 다시 기다려줘요
- 성공하면 별 스티커가 쌓여요
- 오른쪽 아래 작은 ✓ 버튼: 아이가 인사했는데 인식이 안 될 때 부모님이 눌러주세요

## 캐릭터 목소리
배포할 때 GitHub Actions가 `tools/make_voices.py`로 대사마다 아이 같은 목소리 파일(`voices/`)을 만들어요.
공개 한국어 음성 모델(Supertonic)로 읽은 뒤 음높이와 목소리 결을 올려 아이·동물 친구 목소리로 바꿉니다.
대사는 `lines.js`에 있고, 캐릭터별 목소리 설정은 `tools/make_voices.py`의 `VOICES`에서 바꿀 수 있어요.
아이 이름을 '도빈'이 아닌 이름으로 바꾸거나 사진 친구에게 인사할 때는 휴대폰 기본 음성으로 말해요.
